03 · SIMULATION

Manufacturing Process Simulation

Simulation-based study of production flow, bottlenecks, distribution and process optimization.

Download Project Report ↓ All Projects

OVERVIEW

Project Overview

This project uses manufacturing process simulation to study the flow of work through a production system. The model provides a way to examine system behaviour and identify potential constraints.

OBJECTIVES

Project Objectives

  • Represent a production process using a simulation model.
  • Study production flow and resource utilization.
  • Identify bottlenecks and opportunities for process improvement.

METHODOLOGY

Design & Methodology

  • Develop a model of the production process.
  • Represent relevant process stages and flow between them.
  • Run simulation scenarios and examine system performance.

OUTCOMES

Results & Outcomes

  • The available portfolio description identifies production flow, bottlenecks, distribution and process optimization as the main areas of study. Detailed numerical results have not yet been provided.
