# SIERRA1Sula.github.io

Updated portfolio website with individual project detail pages.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub Pages repository.
2. Keep the `projects` and `reports` folders in the same locations.
3. Add your PDF reports to `reports/` using the exact filenames listed in `reports/README.txt`.
4. Ensure the homepage is named `index.html` and the stylesheet is named `style.css`.
